# AI霖子插件数据存储边界

## 跟 AI霖子账号走（云端）

- 学员账号、身份、套餐、积分与连接密钥的哈希
- AI霖子知识库与长期记忆
- 插件产生的主对话消息（使用 `obsidian:` 前缀的 `sessionId` 写入 AI霖子服务端；插件历史云端优先、本机缓存兜底）
- AI 生图调用与账户使用记录

这些数据不依赖 Alina 的个人电脑。更换电脑后，学员重新安装插件并生成新的连接密钥即可继续使用账号。

### 对话历史的单向同步边界

- 插件产生的对话会同步到 AI霖子云端，因此网页版可以显示这些插件对话。
- 插件只列出、读取和删除 `sessionId` 以 `obsidian:` 开头的会话。
- 网页版和微信端产生的对话不进入插件历史；插件单独删除一条或点击“清空全部”都不能删除它们。
- “删除”会同时删除所选 `obsidian:` 云端会话与本机缓存，不影响其他插件会话；删除当前正在查看的会话时，界面才会开启一条新对话。
- 服务端删除条件必须同时包含当前学员身份与 `obsidian:` 命名空间，禁止只按学员账号批量删除。
- 旧云端记录如果没有来源标记，宁可不在插件显示和删除，也不能猜测它来自插件。本机缓存统一由 Obsidian `Plugin.loadData()` 和 `Plugin.saveData()` 管理。

## 跟学员 Vault 走（由学员自行同步或备份）

- 学员自己的 Markdown 笔记
- 插入文章的配图
- 内容发布状态 frontmatter
- 插件产出的选题、公众号文章和分发稿

插件不得把整个 Vault 自动上传到 AI霖子服务器。需要跨设备时，由学员选择 Obsidian Sync、iCloud、OneDrive 或其他 Vault 备份方案。

## 只属于当前设备（不跨设备同步）

- AI霖子连接密钥明文
- 公众号 AppSecret
- 本地插件设置与会话缓存（不是主对话唯一副本）
- 本地 Skill 运行记录：只保存动作名称、程序类型、状态、耗时和生成文件元数据；不保存命令参数、标准输出、错误全文或电脑绝对路径

敏感凭证使用 Obsidian `SecretStorage`。设置页只让用户粘贴密钥值，不显示也不要求填写 SecretStorage 条目名或密钥 ID；内部使用固定的隐藏条目名，`data.json` 不保存密钥明文。设备损坏或更换后，AI霖子 Token 应在连接中心撤销旧密钥并生成新密钥；公众号 AppSecret 应从公众号后台重新填写或重置。

本地 Skill 运行能力默认关闭。开启后，插件会在每次启动程序前展示程序、参数、预计生成文件、联网声明，以及本步终端输出是否会交给 AI，由用户逐步确认。终端输出默认不上传；仅当动作明确申请并经用户确认时，最多 4,000 字会临时交给 AI 继续判断，仍不写入云端对话历史。它不是操作系统沙箱：已确认的 Node/Python 脚本拥有当前 Obsidian 进程可用的本机权限，因此只应运行自己信任的 Skill。撤销只会把本次新生成且未被修改的 Vault 文件移入系统废纸篓，不会回滚脚本造成的其他外部影响。

## GitHub 只保存什么

GitHub 仓库只保存插件源码、测试、文档和正式发布包。任何真实学员 Token、公众号密钥、对话、笔记或配图都不得提交到 GitHub。
