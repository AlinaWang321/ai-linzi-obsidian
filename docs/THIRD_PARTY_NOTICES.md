# 第三方开源组件

AI霖子 Obsidian 插件在本地文档解析、PNG 导出与多格式成品生成中使用以下开源组件：

- [PDF.js / pdfjs-dist](https://github.com/mozilla/pdf.js)，Apache License 2.0
- [fflate](https://github.com/101arrowz/fflate)，MIT License
- [html-to-image](https://github.com/bubkoo/html-to-image)，MIT License
- [docx](https://github.com/dolanmiu/docx)，MIT License
- [pdf-lib](https://github.com/Hopding/pdf-lib)，MIT License
- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)，MIT License

它们只随插件在用户设备本地运行，不连接第三方解析或图片导出服务。许可证原文位于
`third-party-licenses/`。
