## 1. 产品与代码边界：公开插件只是薄客户端

必须始终遵守：

> 公开插件只做界面、本地笔记操作和版本化 API 调用；真正有商业价值的提示词、AI 判断、计费、学员数据和模型编排全部放在私有后端。

公开插件仓库可以包含：

- Obsidian 界面、交互状态和用户主动触发的 Vault 读写。
- 请求参数、响应解析、错误提示与对服务端版本化 API 的调用。
- 不含商业机密的 Markdown 结构解析、TXT/PDF/DOCX/HTML/PPTX/XLSX 本地文字提取、公众号内联排版和本地安全校验。
- 可公开审查的隐私、安全、数据边界文档和回归测试。

公开插件仓库不得包含：

- AI霖子的核心系统提示词、商业判断规则、私有方法论提示词和隐藏验收标准。
- 任何具体模型的密钥、供应商密钥、真实内部接口或可绕过服务端计费的直连能力。
- 学员资料、长期记忆、账号权益、余额、扣费明细或其他服务端真相源数据。
- 模型选择、降级、重试、计费、风控和多模型编排的核心实现。
- 任何能让第三方仅复制公开仓库就复刻 AI霖子核心能力的代码或配置。

需要新增 AI 能力时，先在私有 AI霖子 webapp 后端实现，再通过 `/api/plugin/v1/*` 暴露最小必要接口。插件不能为省事复制后端提示词或直接连接模型供应商。

## 2. 用户数据与凭证

- 学员文档、配图和内容状态默认留在学员自己的 Vault。v0.7.18 起没有「带上当前笔记」勾选项：只有用户文字明确要求处理当前/这篇笔记，或继续上一轮已经锁定的当前笔记任务时，插件才读取单篇 Markdown，并向用户显示实际文件名；v0.7.21 起目标 Markdown 必须仍存在于打开的标签页中，关闭标签页立即撤销授权，禁止回退 `lastActiveFile` 或 Obsidian 最近打开记录，普通闲聊不读。v0.7.17 起也没有「智能搜索 Vault」开关；v0.7.30 起所有合适的纯文字主对话都向 Luna 提供受限本机工具能力，由 Luna 自己判断是否需要 Markdown、TXT、可复制文字的 PDF 或 DOCX，而不是客户端先匹配 Vault/知识库/档案等关键词。在 Luna 真正请求工具前不得预扫、读取或发送任何 Vault 片段；普通闲聊必须零调用。不得建立云端索引或上传整个 Vault。用户主动打开精确选择器时，可以按 Vault 目录勾选整篇 Markdown 正文，但未确认的正文不得发送。
- 只有用户明确触发当前笔记任务、精确文件授权、喂库、配图、发布或更新笔记时，才读取和发送该动作所需的最小内容。
- Token、公众号 AppSecret 等敏感凭证必须进入 Obsidian `SecretStorage`；不得写入 `data.json`、日志、Git、报错文本或分析事件。
- 设置页不得暴露 `SecretStorage` 条目名或要求用户填写密钥 ID。AI霖子连接密钥和公众号 AppSecret 都使用单一密码输入框，内部固定条目名只属于实现细节。
- AI霖子云端负责账号、权益、积分、知识库、插件云端对话及模型调用记录；这些数据不得依赖 Alina 的个人电脑。
- 本地写入必须有明确的用户动作。更新当前笔记、应用局部补丁、覆盖图片与公众号发布都不得静默执行。
- 对话输入默认使用 Enter 换行，界面统一提示 Mac / Windows 使用 `Control + Enter` 发送；Mac 的 `Command + Enter` 继续作为兼容快捷键，用户也可点击右下角发送按钮。不得恢复为单按 Enter 直接发送。

## 3. 对话历史：插件到云端的单向可见性

目标关系：

- 插件产生的对话同步到 AI霖子云端，网页版可以查看这些对话。
- 网页版或微信端产生的对话绝不反向同步到 Obsidian 插件。
- 插件“历史”只显示插件产生的对话；支持单独删除一条或清空全部，但都只能删除插件产生的对话。

强制实现规则：

1. 插件会话 `sessionId` 必须使用固定前缀 `obsidian:`。
2. 插件的列表、读取、标题和删除 API 必须在数据库查询层同时限制当前 `student_no` 与 `session_id LIKE 'obsidian:%'`。
3. 禁止依赖客户端传来的 `channel` 作为唯一隔离条件；禁止插件删除接口只按 `student_no` 执行批量删除。
4. 网页端仍可读取学员全部合法云端会话，因此能看到插件会话；插件端只能读取插件命名空间。
5. 旧插件发送普通 UUID 时，新的插件聊天写入 API 在服务端补上 `obsidian:` 前缀。
6. 历史遗留的无前缀云端会话来源不可靠，插件必须排除，不能为了“看起来完整”而冒险显示或删除。本机缓存必须使用 Obsidian `Plugin.loadData()` 和 `Plugin.saveData()` 管理。
7. 插件单删和清空确认文案都必须明确说明：其他插件会话、网页版与微信端对话不受影响。

任何修改对话存储、恢复、跨端同步、单删或清空逻辑的提交，都必须同时运行客户端和服务端的会话隔离测试。

## 4. API 与后端边界

- 插件的新能力优先走 `/api/plugin/v1/*`；旧接口只做明确、限时的兼容，不继续扩张。
- 鉴权、授权、套餐校验、积分扣减、幂等、审计和访问范围必须由服务端执行，不能信任客户端 UI 状态。
- API 返回插件完成当前界面动作所需的最小数据，不把内部提示词、供应商响应、模型路由或学员完整档案返回客户端。
