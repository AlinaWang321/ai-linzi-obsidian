# AI霖子 Obsidian 插件安装说明

> 适用于 Windows、macOS 的 Obsidian 桌面版。请先把 Obsidian 更新到 1.11.4 或以上版本；暂不支持手机版。

## 官方市场安装（推荐）

1. 打开 Obsidian「设置 → 第三方插件」，确认已关闭安全模式。
2. 点击「浏览」，搜索 **AI Linzi**。
3. 点击「安装」，安装完成后点击「启用」。
4. 登录 AI霖子网页版，进入「连接中心」，生成一把连接密钥。
5. 回到 Obsidian 的「设置 → AI霖子」，粘贴连接密钥并点击「测试连接」。

## 手动安装（只用于开发验收或官方目录临时不可用）

1. 解压下载的 `ai-linzi.zip`，得到 `ai-linzi` 文件夹。
2. 打开你的 Obsidian 仓库，在电脑文件管理器中显示隐藏文件。
3. 把整个 `ai-linzi` 文件夹放进：`你的仓库/.obsidian/plugins/`。

   ![macOS 安装位置示范：把 ai-linzi 文件夹放进仓库的 .obsidian/plugins 文件夹](img/install-location.png)

   > macOS 如果看不到 `.obsidian`，请在 Finder 同时按下 `Command + Shift + .` 显示隐藏文件夹。

4. 重启 Obsidian，打开「设置 → 第三方插件」，刷新已安装插件并启用「AI霖子」。
5. 登录 AI霖子网页版，进入「连接中心」，生成一把连接密钥。
6. 回到 Obsidian 的「设置 → AI霖子」，粘贴连接密钥并点击「测试连接」。

   ![AI霖子连接密钥粘贴位置：Obsidian 设置 → 第三方插件 → AI霖子 → AI霖子连接密钥](img/connection-key-location.png)

   > 只需要粘贴网页端生成的连接密钥，不需要填写密钥名称或 ID。

> Windows 显示隐藏文件：文件资源管理器 → 查看 → 显示 → 隐藏的项目

### Windows 看不到 AI霖子时

请打开 `你的仓库/.obsidian/plugins/ai-linzi/`，确认这一层能直接看到：

- `manifest.json`
- `main.js`
- `styles.css`

最终路径必须是：

`你的仓库/.obsidian/plugins/ai-linzi/manifest.json`

如果实际路径是：

`你的仓库/.obsidian/plugins/ai-linzi-obsidian/ai-linzi/manifest.json`

说明 Windows 解压时多套了一层。请把里面的 `ai-linzi` 文件夹移动到 `plugins` 目录，删除外层空的 `ai-linzi-obsidian` 文件夹，然后完全退出并重新打开 Obsidian。

## 以后更新

正式版本请在 Obsidian「设置 → 第三方插件」中检查并安装更新。插件没有自更新器，版本安装完全交给 Obsidian 官方机制。

通过 AI霖子网页版连接中心安装开发验收包的用户，可以重新下载对应测试包并覆盖 `main.js`、`manifest.json` 和 `styles.css`；正式使用时建议切回官方市场版本。覆盖这三个文件不会覆盖你的笔记、账号云端对话或公众号配置。

## 安全说明

- 不需要开启“智能搜索”开关。所有适合的主对话都会向当前选择的大模型提供受限 Vault 工具，但只有模型为完成你的请求真实调用搜索或读取工具后，插件才会在本机检索；普通闲聊保持零文件读取。插件只把回答所需的少量结果交给 AI，不会上传整个 Vault，也不会建立云端全文索引。
- AI 可以分步请求“继续搜索、查看目录、读取某篇文档的一段”，但所有读取都由插件在你的电脑上校验执行，AI 没有直接磁盘权限。工具过程和本地路径不会进入云端聊天历史。
- 当你要求整理、移动、重命名或删除笔记时，AI 只先核实真实路径并给方案；你在 Obsidian 再次确认后插件才执行。删除功能（0.7.42 起）支持批量与任意文件/文件夹：AI 先核实路径并在确认卡逐条列出待删清单，你再次确认后才把它们移入系统废纸篓/回收站（系统不允许时由 Obsidian 放入 `.trash`），永远不会永久删除；含本地 Skills 根目录等受保护路径的文件夹会整单拒绝。移动/重命名可用命令面板「撤销上一次 AI Vault 整理」恢复；回收站笔记请从回收站恢复。
- 小红书卡片、公众号写作/分发、文章配图、销售复盘、客户咨询简报等任务一旦启动，就锁定当时选择或打开的原笔记；生成期间可以继续浏览其他笔记，不会换掉正在处理的来源。
- 你明确说“处理当前笔记/这篇文章”时，仍然打开的一篇 Markdown 会成为首要材料；关闭标签页立即撤销这份精确上下文。你点名某个文件或文件夹时，它只是本轮优先搜索范围，资料不足时仍可继续搜索当前整个 Vault；这些工具永远不能读取 Vault 外的电脑文件。主动选择的整篇文档、图片修改和公众号发布，仍然只有在你主动选择或确认后才会发送或执行。
- AI霖子连接密钥和公众号 AppSecret 只需直接粘贴，无需填写密钥名称或 ID；它们存在当前设备的 Obsidian 安全存储中，不会写入笔记或上传 GitHub。
- 换电脑后重新安装插件并生成新的连接密钥即可；云端账号、权益和插件对话不依赖原来的电脑。
- 插件对话中手工修改的标题会作为账号会话元数据同步，方便换设备后继续识别；标题不会放进 AI 提示词。图片确认卡、Vault 路径和 Skill 更新的本轮内存回滚数据只留在本机；插件不建立 Skill 历史版本。
