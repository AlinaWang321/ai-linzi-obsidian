# 0.7.74 对话标题开发与验收方案

> 状态：开发中。范围只包含插件对话标题的编辑、持久化与跨端合并；不改变聊天正文、网页版/微信历史或会话删除范围。

## 数据合同

1. `SavedConvo.title` 继续保存当前有效标题，兼容旧版本。
2. 新增 `titleOverride`、`titleUpdatedAt`、`titleSyncPending`：字符串是手工标题；`null` 是用户明确清空后的 tombstone；缺字段表示从未改名。
3. 标题最多 60 个 Unicode 码点，换行压成空格；标题只用于历史列表，不进入主对话消息或模型上下文。
4. 本机与云端都有明确状态时，以 `titleUpdatedAt` 较新者为准；同刻以云端为准，使两端收敛。
5. 本机标题先保存但云端暂时失败时保留 `titleSyncPending`，下一次成功对话或打开历史时重试，不因网络错误丢掉本机标题。

## 服务端隔离

- 只新增 `/api/plugin/v1/chat/sessions` 的 `PATCH`，使用插件 PAT，不复用网页 cookie 改名接口。
- 会话存在性查询同时限制当前 `student_no`、`session_id LIKE 'obsidian:%'` 和精确 `session_id`。
- 标题元数据只 upsert 到同一学员、同一插件会话；空标题保留 `title=null` 与更新时间，保证跨设备清空可传播。
- 插件会话列表返回 `titleUpdatedAt`；网页版和微信端会话不在插件接口范围内。

## 客户端链路

- 历史行新增“改名”，保存前可编辑，留空即恢复第一条问题生成的标题。
- `persistNow`、本机保存、云端转换、历史展示和打开会话全部使用同一标题状态。
- 新对话、进入/退出访谈、删除当前会话、清空全部都会清掉活动标题状态，不串到下一条会话。
- 云端消息较新但本机含图片卡/Vault 来源时仍保留更丰富的本机正文；标题单独按更新时间合并，互不覆盖。

## 验收门禁

1. 纯逻辑测试：码点限长、换行、手工标题、清空 tombstone、本机较新、云端较新、同刻收敛、畸形状态。
2. DOM 行为测试：预填、聚焦、保存、留空回退、Enter、Escape、关闭只 resolve 一次。
3. 服务端测试：输入清洗、PAT 路由、三重查询隔离、标题写入隔离、云端更新时间返回。
4. 完整门禁：插件 `npm test/build/check:marketplace/package:release`，WebApp `test:plugin-api/tsc/build`。
5. 原生验收：数字大脑真实改名 → 关闭重开仍在 → 继续对话不被自动标题覆盖 → 清空回退 → 新对话不串名。

## 发布边界

开发提交、测试 Vault 安装和开发分支服务端都不等于生产发布。真实界面与全量门禁未完成前，不打标签、不建 Release、不更新 production latest；WebApp 未明确批准前不推生产 `main`。
