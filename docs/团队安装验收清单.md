# AI霖子 Obsidian 插件团队安装验收清单

> 用于密训前的 Windows、macOS 实机测试。普通学员只需要阅读安装包内的 `INSTALL.md`。

## 一、测试环境

- [ ] Windows 10 或 Windows 11，Obsidian 1.11.4 或以上
- [ ] macOS，Obsidian 1.11.4 或以上
- [ ] 至少测试一个已有大量笔记的 Vault
- [ ] 至少测试一个新建的空白 Vault

## 二、下载安装

- [ ] 从 AI霖子网页版「连接中心」下载最新安装包
- [ ] Windows“全部解压”后，最终路径为 `.obsidian/plugins/ai-linzi/manifest.json`
- [ ] macOS 能按说明显示 `.obsidian` 隐藏文件夹
- [ ] 完全重启 Obsidian 后，能在「设置 → 第三方插件」看到并启用「AI霖子」

## 三、账号连接

- [ ] 在网页版生成连接密钥时不要求填写“密钥 ID”
- [ ] 在 Obsidian「设置 → AI霖子」只需粘贴「AI霖子连接密钥」
- [ ] 点击「测试连接」后能看到当前账号或学号
- [ ] 在网页版吊销密钥后，旧密钥立即不能继续使用
- [ ] 重新生成并粘贴新密钥后，可以恢复连接

## 四、基础功能冒烟测试

- [ ] 主对话可以正常发送并收到回复
- [ ] 打开一篇 Markdown 并说“总结当前笔记”后，AI 只读取这一篇；关闭标签页后再次请求会提示重新打开，不会读取旧笔记
- [ ] 分别用“知识库、数字大脑、文件仓库、Obsidian”提出查找要求，都能自动返回可点击的来源文档；普通闲聊不扫描
- [ ] 对话区显示“我的 Skills”，说“查看我的 Skills”和旧说法“查看本地 Skills”都能列出用户自建 Skill
- [ ] 调用一个账号有权限的技能可以正常完成
- [ ] 从笔记 A 启动小红书卡片或另一个耗时技能后立刻浏览笔记 B，最终结果仍引用 A，不读取 B
- [ ] 明确要求删除一篇测试 Markdown 时先出现方案卡，再出现单独确认；取消不改变文件，确认后只进入系统回收站或 Obsidian `.trash`，可恢复
- [ ] 删除方案不能包含两篇笔记，不能删除附件或文件夹，也找不到任何“永久删除”入口
- [ ] Starter、Pro、Business 各自只能使用对应权益

## 五、更新测试

- [ ] 官方市场审核通过后，从「设置 → 第三方插件」检查并安装更新
- [ ] 审核通过前，从 AI霖子网页版连接中心重新下载最新版，覆盖 `main.js`、`manifest.json` 和 `styles.css`
- [ ] 完全重启 Obsidian 后，插件版本正确
- [ ] 更新不会覆盖已有笔记、本地对话、公众号配置和密钥

## 六、“我的 Skills”运行专项（v0.7.11 起，需分别验收 Windows/macOS）

- [ ] 升级后「允许“我的 Skills”运行程序」默认关闭
- [ ] 服务端或插件版本不支持时，开关会恢复关闭并提示更新，不出现假开启
- [ ] 调用可信测试 Skill 时，必须先完整读取脚本，再出现执行确认弹窗
- [ ] 弹窗能看清程序、参数、工作目录、最长时间、联网声明、预计生成文件，以及终端输出是否交给 AI
- [ ] 点击「取消这一步」不会启动程序、不会生成文件，也不会反复请求同一步
- [ ] 点击「允许执行」后只新建声明的输出；同名文件存在时拒绝覆盖
- [ ] 终端输出默认不交给 AI；明确申请时弹窗必须写明最多 4,000 字且不写云端历史
- [ ] 完成卡显示真实状态和生成文件；声明文件未生成时显示失败，不能冒充成功
- [ ] 「移到系统废纸篓/回收站」只处理本次新生成且未修改的 Vault 文件，能从系统废纸篓恢复
- [ ] 生成后手动修改文件，再点撤销时必须拒绝，避免误删用户改动
- [ ] 分别记录 Node.js、Python、FFmpeg/FFprobe 是否已安装；缺失时给出明确提示，不自动联网安装依赖

## 七、问题反馈格式

如果失败，请一次性记录：

1. Windows 或 macOS 版本
2. Obsidian 版本
3. AI霖子插件版本
4. 出错步骤和完整报错截图
5. `.obsidian/plugins/ai-linzi/` 文件夹截图
6. 是否已经完全退出并重新打开 Obsidian

不要在截图或群聊中展示完整连接密钥、公众号 AppSecret 或其他私密信息。
