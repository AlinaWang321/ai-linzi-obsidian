# AI霖子 Obsidian 插件团队安装验收清单

> 用于密训前的 Windows、macOS 实机测试。普通学员只需要阅读安装包内的 `INSTALL.md`。

## 一、测试环境

- [ ] Windows 10 或 Windows 11，Obsidian 1.11.4 或以上
- [ ] macOS，Obsidian 1.11.4 或以上
- [ ] 至少测试一个已有大量笔记的 Vault
- [ ] 至少测试一个新建的空白 Vault

## 二、下载安装

- [ ] 从 AI霖子网页版「连接中心」下载最新安装包
- [ ] Windows“全部解压”后，最终路径为 `.obsidian/plugins/ai-linzi/manifest.json`
- [ ] macOS 能按说明显示 `.obsidian` 隐藏文件夹
- [ ] 完全重启 Obsidian 后，能在「设置 → 第三方插件」看到并启用「AI霖子」

## 三、账号连接

- [ ] 在网页版生成连接密钥时不要求填写“密钥 ID”
- [ ] 在 Obsidian「设置 → AI霖子」只需粘贴「AI霖子连接密钥」
- [ ] 点击「测试连接」后能看到当前账号或学号
- [ ] 在网页版吊销密钥后，旧密钥立即不能继续使用
- [ ] 重新生成并粘贴新密钥后，可以恢复连接

## 四、基础功能冒烟测试

- [ ] 主对话可以正常发送并收到回复
- [ ] 勾选当前笔记后，AI 能读取当前笔记
- [ ] 开启「智能搜索 Vault」后，能返回可点击的来源文档
- [ ] 调用一个账号有权限的技能可以正常完成
- [ ] Starter、Pro、Business 各自只能使用对应权益

## 五、更新测试

- [ ] 官方市场审核通过后，从「设置 → 第三方插件」检查并安装更新
- [ ] 审核通过前，从 AI霖子网页版连接中心重新下载最新版，覆盖 `main.js`、`manifest.json` 和 `styles.css`
- [ ] 完全重启 Obsidian 后，插件版本正确
- [ ] 更新不会覆盖已有笔记、本地对话、公众号配置和密钥

## 六、问题反馈格式

如果失败，请一次性记录：

1. Windows 或 macOS 版本
2. Obsidian 版本
3. AI霖子插件版本
4. 出错步骤和完整报错截图
5. `.obsidian/plugins/ai-linzi/` 文件夹截图
6. 是否已经完全退出并重新打开 Obsidian

不要在截图或群聊中展示完整连接密钥、公众号 AppSecret 或其他私密信息。
